# Project structure

This layout separates reusable code, exploratory notebooks, generated experiment artifacts, and assessment documentation. It is a recommended organization, not a requirement stated by the assessment brief.

- `src/data/`: future data-loading and preprocessing code.
- `src/models/`: future model definitions.
- `src/training/`: future training routines and configuration handling.
- `src/evaluation/`: future evaluation and metrics code.
- `src/utils/`: future shared helpers.
- `notebooks/`: notebooks, if useful and permitted by the brief.
- `experiments/results/`: structured result summaries.
- `experiments/plots/`: generated visualizations.
- `experiments/logs/`: run logs.
- `checkpoints/`: saved model state, subject to storage/submission rules.
- `reports/`: report drafts and final assessment materials.

Review data storage and submission requirements against the official brief before placing files in these locations.
