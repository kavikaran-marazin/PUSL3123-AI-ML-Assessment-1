# Handover protocol

At the end of a work session, update `docs/team-and-handover.md` with:

- Date and contributor identifier.
- Work completed, with file paths or commit reference where useful.
- Decisions made and their basis (brief citation, team choice, or recommendation).
- Commands run and outcomes, distinguishing executed checks from proposed commands.
- Current blockers, open questions, and next actions with an owner if agreed.
- Any uncommitted or generated files another member needs to know about.

Before handing off, leave the repository in a readable state and do not claim work is complete if required brief details remain unverified.
